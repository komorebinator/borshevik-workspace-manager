# BorshevikWorkspaceManager

GNOME Shell extension for Borshevik Linux — replaces GNOME's default workspace behaviour with an opinionated tiling + workspace management system.

---

This project is described with [duckspec](https://github.com/komorebinator/duckspec): the specification lives in [spec/BorshevikWorkspaceManager.yaml](spec/BorshevikWorkspaceManager.yaml), and [spec/AGENTS.md](spec/AGENTS.md) explains how to load it.
